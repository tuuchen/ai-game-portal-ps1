# Cortex Ignition redistribution audit

- Game release: Cortex Ignition Tech Demo 2026.09.05, official itch download. The release includes GPL-2.0 license text, a PSoXide copyright/redistribution notice, SHA-256 receipt, and source commit `0f12f4d8f5ebaf2ab3bdf0bd1a7a0469166d7c58`.
- Corresponding source: https://github.com/EBonura/PSoXide-editor/tree/0f12f4d8f5ebaf2ab3bdf0bd1a7a0469166d7c58 with SDK `7b929ce473ed44b10b0ffca08f413eebf4eeeec4` and emulator-core `fd914c5ed8fbb0b46f8276c5ff7376904b9b444f` pinned by `components.lock.json`.
- Known permissive assets: gameplay documentation identifies CC0 sources from OpenGameArt and Kenney; UI placeholders are CC0 by Brian MacIntosh; controller prompts are Kenney CC0.
- Provenance limitation: the source notes say several author-supplied voice, weapon, dash, stance and intro recordings are separate from the CC0 sources, and their independent upstream licenses are not recorded. The official author nevertheless distributes the assembled release under the included GPL notice. This audit records that gap and does not represent those individual recordings as CC0.
- Emulator: PSoXide, GPL-2.0-or-later. Deployed official browser build snapshot downloaded from the PSoXide itch release on 2026-09-14; source repository snapshot `38af605ac5a6961f3798d432bcfb7cceacece239`.
- Portal wrapper: original integration code in this repository, MIT licensed.

Official release: https://bonnie-studios.itch.io/cortex-ignition
