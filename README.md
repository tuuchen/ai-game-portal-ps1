# AI Game Portal — PlayStation homebrew

Production hosting for two real PS1 homebrew disc images used by the AI Game Portal:

- VoXide v0.1.11
- Cortex Ignition Tech Demo 2026.09.05

Both use one shared PSoXide WebAssembly runtime. The portal entries are thin launchers; GitHub Pages hosts the larger immutable emulator and streamed disc assets. Original BIN/CUE downloads are attached to the GitHub release.

No Sony BIOS is included: PSoXide fast-boots homebrew with its high-level boot path.

See `LICENSE-AUDIT-VOXIDE.md` and `LICENSE-AUDIT-CORTEX.md` before redistributing.
